# Native action guidance and early publication

The owner identified that claim reminders combine native admission explanations
with a TypeScript procedural-obligation catalog. Documented the required migration:
native obligations/applicability/order, shared generated English and no independent
command policy fallback. Keeping strings in a data file is not sufficient.

Added the separate early-publication duty: push coherent locally checked changes
promptly, open a useful draft PR early, keep its status honest, and retain ordinary
checks, privacy and merge safeguards. This supports recoverability, designer
visibility and incremental review; it does not automatically publish work.

Delivery is split into a reviewed contract, native claim-obligation migration,
early-publication policy and claim projection/removal of the old catalog. Existing
release and submission tickets reuse the mechanism. No runtime behavior or live
repository configuration changes in this documentation work.
