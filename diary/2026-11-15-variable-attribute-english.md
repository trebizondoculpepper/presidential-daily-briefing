# Variable attributes in compiled English (#500)

The merged rules-English contract permits variable attributes, but the compiler rejected them. Added a distinct dynamic-fact clause retaining entity, attribute and value terms. It uses literal structural prose, with no guessed viewer/context scope or lexicon lookup. Wildcards retain existential matching; string attributes retain the existing lexicon validation.

The English model shape is version 2. Production policy source, policy hash, decisions, ordering and runtime reasons are unchanged; the production English artifact changes only its model version. Synthetic fixtures execute variable/wildcard queries in the pinned DataScript engine and check rendering and literal-versus-variable validation. No live GitHub data or model calls are involved in these tests.
