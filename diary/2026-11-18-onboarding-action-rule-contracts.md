# Onboarding and generated action-rule handoff

Captured the owner's minimal npm-install hint, explicit project onboarding file
writes, and policy-first action reminders. Claim, release and submission have
separate policy/display slices, with existing ownership admission reused rather
than duplicated. Generated rules.md is a marked refreshable snapshot; unrelated
AGENTS.md content and edited files remain protected.

Inspected GitHub's ruleset, head-branch rules, separate Update branch setting and
read-only merge-tree results. No explicit conflict-editor prohibition was found;
the historical disabled button cannot be attributed without specific browser/PR
evidence. No repository settings were changed. Documentation does not implement
these runtime features.
